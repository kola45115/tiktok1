# TikTok Mod (без root)

Модуль на Xposed API, который вшивается в **ваш** TikTok через LSPatch → получается один APK, root не нужен.
Чужой код TikTok в репозитории не лежит и не распространяется.

## Что умеет
- **Смена региона** — подмена `TelephonyManager` (страна/оператор SIM и сети). Работает на любой версии TikTok, имена классов не нужны.
  Ограничение: сервер видит ещё и IP — для ленты другой страны нужен VPN.
- **Тема/UI** — перекраска цветов по имени ресурса (HEX + regex). Debug-режим пишет имена цветов в logcat (`adb logcat -s TTMod`), чтобы подобрать нужные.
- **Окно настроек** — коснитесь экрана TikTok **тремя пальцами**.
- **Лента (проверено по dex 47.x):** убрать рекламу, LIVE, AI-видео (`FeedItemList`, `Aweme`).
- **Скачивание без водяного знака** (`Video.getDownloadNoWatermarkAddr`).

## Сборка
1. Залейте папку в GitHub → вкладка Actions → `build-module` → скачайте `app-debug.apk`.
   (Локально: Android SDK + `gradle :app:assembleDebug`.)
2. Скачайте `lspatch.jar` (releases JingMatrix/LSPatch) и свой TikTok (bundle: base + split_*.apk).
3. `./patch.sh app-debug.apk base.apk split_config.*.apk`
4. Удалите оригинальный TikTok, `adb install-multiple out/*.apk`.

## Статус
Код не компилировался и не запускался в среде автора (нет Android SDK и доступа к Maven) — первая сборка может потребовать мелких правок.


## Тема (обновлено)
По `resources.arsc` выяснено: имена ресурсов обфусцированы, поэтому тема красит по значению: фирменный #FE2C55 (и #FF3B5C) заменяется на выбранный акцент с сохранением прозрачности. Поле regex осталось как резерв. Индекс цветов: `colors_index.json`.
Ограничение: цвета, взятые через атрибуты темы или зашитые в drawable/векторах, этот хук не затронет.
